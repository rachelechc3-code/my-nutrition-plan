# My Nutrition Plan

PWA prototipale mobile-first, in stile Quiet Luxury, basata sulla scheda nutrizionale del Dr. Panetto Ettore del 30/09/2026.

## Installazione su iPhone
La modalità "Aggiungi alla schermata Home" richiede che la cartella sia pubblicata su un URL HTTPS. Una volta pubblicata:
1. Aprire l'URL in Safari.
2. Toccare Condividi.
3. Toccare "Aggiungi alla schermata Home".
4. Confermare "Aggiungi".

## Stato della build
Funzionano localmente: navigazione, settimana 1-7 senza duplicati, colazioni intercambiabili, check allenamento, libreria ricette, stagionalità mensile + aggiunte manuali, storico e checkbox spesa.

Da completare per una release pubblicata: importazione/analisi automatica del nuovo PDF del nutrizionista, calcolo aggregato della lista della spesa in base alle scelte effettive e notifiche di sistema alle 20:00. Queste funzioni richiedono un backend/servizio di pubblicazione e test su dispositivo reale.
